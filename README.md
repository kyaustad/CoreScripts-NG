# CoreScripts

These are the scripts used to implement most of the essential server logic in TES3MP, including gameplay adjustments for multiplayer as well as state saving and loading.

* TES3MP-NG version: 0.51 ([TES3MP-NG](https://github.com/kyaustad/TES3MP-NG) follows OpenMW's version numbers:
  0.51.x is based on OpenMW 0.51, replacing TES3MP's 0.8.x numbering)
* CoreScripts-NG is a modified version of [TES3MP's CoreScripts](https://github.com/TES3MP/CoreScripts), changed
  from 2026 on for TES3MP-NG. It is not made or endorsed by the TES3MP developers.
